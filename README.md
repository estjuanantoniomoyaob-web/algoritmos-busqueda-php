# Algoritmos de Búsqueda en PHP

## Descripción

Ejemplos de búsqueda en arreglos unidimensionales y bidimensionales utilizando PHP.

## Ejecución desde CMD

Abrir la consola:

```text
Windows + R → escribir "cmd" → Enter
```

Luego ejecutar:

```cmd
cd C:\Users\USUARIO\algoritmos-busqueda-php
cd ejemplos
```
### Ejemplo 1 - Arreglo unidimensional
```cmd
C:\laragon\bin\php\php-8.1.10-Win32-vs16-x64\php.exe ejemplo1_unidimensional.php
```
### Ejemplo 2 - Arreglo bidimensional
```cmd
C:\laragon\bin\php\php-8.1.10-Win32-vs16-x64\php.exe ejemplo2_bidimensional.php
```
